# Simple Data Cleaning Analysis Python

This Python script demonstrates fundamental data cleaning and analysis techniques, mirroring capabilities found in Microsoft Excel. It processes a simulated dataset with inconsistencies, standardizes product names, handles missing or invalid numeric values, and then performs basic aggregations and calculations like total revenue and average sale value.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
